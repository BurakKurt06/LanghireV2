# Bundled data

`us_places.csv.gz`: US postal codes with place name, state and coordinates
(zip, city, state, lat, lon), used for the free location check against the
user's search area. Derived from the GeoNames postal code dataset
(https://download.geonames.org/export/zip/US.zip), licensed under
Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/).
Changes: kept five columns, rounded coordinates to 4 decimals.
